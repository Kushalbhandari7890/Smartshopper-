# SmartShopper 🛒

A real-time price comparison tool for Indian e-commerce platforms — built to help shoppers find the best deals across Amazon, Flipkart, Meesho, Myntra, and Jio Mart without manually checking each site.

## 🚀 Features
- Real-time price scraping from multiple Indian e-commerce platforms
- Side-by-side price comparison for the same product
- Clean, simple web interface for quick searches
- Backend built with Node.js for handling scraping and routing efficiently

## 🛠️ Tech Stack
- *Backend:* Node.js, Express
- *Frontend:* HTML, CSS, JavaScript
- *Scraping:* Custom scrapers for Amazon, Flipkart, Reliance Digital

## 💡 Why I Built This
Comparing prices across Indian e-commerce platforms usually means opening 4-5 tabs manually. SmartShopper automates that by pulling live prices into one place, saving time and helping users make smarter buying decisions.
